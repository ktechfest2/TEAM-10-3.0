# Pitch pack

Read the codebase, README, CLAUDE.md, and the challenge brief's judging criteria first.

1. **Narrative (problem → insight → solution → demo → impact → ask).** Open with a concrete user story or striking stat. Map every claim to a judging criterion.
2. **Slide outline** (6–8 slides max): title, problem, solution, live demo, how it works (architecture), impact/market, team, next steps. Offer to build the deck as slides.
3. **Demo script** timed to the pitch slot (default 3 min): exact clicks, sample inputs, what to say at each step, and a fallback (screenshots/video) if live demo fails.
4. **Judge Q&A**: 10 likely tough questions (scalability, business model, why you, what's real vs mocked, privacy) with crisp answers.
5. **README polish**: pitch, screenshots placeholder, live link, setup steps that actually work, tech stack, team.
