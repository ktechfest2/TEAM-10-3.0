## Theme & challenge (CONFIRMED)
- Theme: **"Building Trust in Governance Using Technology"**
- Challenge: **"Every Vote, Every Voice"**. Pick a weak link in Nigeria's voting chain and strengthen it. Show the big picture, then go deep. Must work for:
  - basic phones
  - voters who don't read English
  - areas with poor network
  - officials, agents and community leaders
- The full brief is in `problem-brief.md`.

## Deliverables (CONFIRMED)
1. One-page problem brief
2. System sketch (diagram)
3. Working prototype or clickable demo of the core feature
4. 3-minute live demo
5. Two-phase submission: code in the GitHub repo, **plus** the official form
   - public/shared GitHub repo
   - demo video of at most 3 minutes
   - short write-up: problem, solution, **how AI is used**, tools used
   - live demo link (via the form)

The brief says extras such as more features, user testing and an integration plan **are rewarded**.
